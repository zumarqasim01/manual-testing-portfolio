# Manual Testing Portfolio

## Project Overview
This project contains sample manual testing scenarios and test cases for a demo login page.

## Test Cases

| Test Case ID | Scenario | Steps | Expected Result |
|---|---|---|---|
| TC-001 | Valid Login | Enter valid credentials and click Login | User should log in successfully |
| TC-002 | Invalid Login | Enter an incorrect password | An error message should appear |
| TC-003 | Empty Fields | Leave both fields empty and click Login | Required field validation should appear |
| TC-004 | Password Masking | Enter a password | Password should be hidden |
| TC-005 | Login Button | Open the login page | Login button should be visible and usable |

Note: These are sample test cases for practice. They have not yet been executed.
